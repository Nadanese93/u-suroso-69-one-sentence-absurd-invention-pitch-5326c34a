A Make.fun bounty entry: one sentence pitching an absurd invention that
fixes a tiny everyday annoyance — a wobbly café table whose shortest leg
quietly grows a tiny wooden foot whenever it rocks, so your coffee stops
doing the salsa and you stop wedging folded napkins under it.

`main.py` (Python 3, standard library only) writes the pitch to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing
newline, and verifies the written bytes by reading them back.
